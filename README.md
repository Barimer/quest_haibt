# 🎮 QUEST HABIT: Life RPG (v3.0)
> **"합격까지의 56일 여정, 컵헤드 스타일의 빈티지 카툰으로 즐기다."**
> 1-4-7-14 복습 알고리즘이 적용된 고효율 학습 관리 RPG.

---

## 📽️ Project Overview
**QUEST HABIT**은 지루한 수험 생활과 습관 관리를 흥미진진한 몬스터 전투로 바꾼 모바일 전용 웹 애플리케이션입니다. 1930년대 빈티지 카툰 감성의 강렬한 비주얼과 과학적인 복습 주기를 결합하여 최상의 학습 효율과 성취감을 제공합니다.

### ✨ Key Aesthetics
*   **Cuphead 테마:** 두꺼운 테두리, 레트로 폰트, 노이즈 필터 효과 적용.
*   **빈티지 연출:** 영사기 플리커(Flicker) 애니메이션과 양피지 컬러 팔레트.
*   **다이내믹 전투:** 피격 흔들림, 데미지 팝업, 몬스터 처치 시 유령 연출(`monster_dead.png`).

## ⚔️ 핵심 시스템 (Core Mechanics)

### 1. 1-4-7-14 복습 스케줄 (D-Day System)
뇌과학에 근거한 망각 곡선 이론을 바탕으로 설계된 56일 집중 학습 스케줄입니다.
*   **일일 퀘스트:** 매일 정해진 신규 학습과 1일 전, 4일 전, 7일 전, 14일 전 복습 과제가 자동으로 배정됩니다.
*   **공격권(Ticket) 지급:** 학습의 난이도와 중요도에 따라 태스크 완료 시 차등화된 공격권이 지급됩니다.
*   **All Clear 보너스:** 오늘의 모든 스케줄을 완료하면 **지능(INT) +1** 보너스를 획득합니다.

### 2. 학습 캘린더 (Study History)
*   퀘스트 탭의 **학습 달성률 바**를 클릭하여 56일간의 전체 진행 상황을 확인합니다.
*   **🌟 (참 잘했어요!):** 100% 달성 완료.
*   **차등 표시:** 미달성일은 달성률(%)이 표시되며, 완료하지 못한 과거 날짜는 ⚠️ 경고 표시가 뜹니다.

### 3. 부가 퀘스트 (Custom Habits)
*   운동, 독서, 식단 등 학습 외적인 개인 습관을 직접 추가/편집할 수 있습니다.
*   완료 시 ATK, INT, HP, MP 등 캐릭터의 영구 스탯 보상을 제공합니다.

## 🧰 캐릭터 성장 및 전리품

| 스탯 | 연관 활동 | 효과 |
| :--- | :--- | :--- |
| **공격력(ATK)** | 운동/부가퀘스트 | 몬스터에게 주는 기본 대미지 결정 |
| **지능(INT)** | 독서/All Clear | 크리티컬 확률 상승 (1당 2%, 최대 50%) |
| **정신력(MP)** | 수면 | 행동 자원 및 대미지 보정 (수면 시간에 비례해 회복) |
| **공격권(Ticket)** | 일일 퀘스트 | 몬스터를 공격할 수 있는 기회 |

### 🎁 의문의 금고 (Mystery Safe)
몬스터 처치 시 획득하는 금고를 통해 확률적으로 희귀 보상을 얻습니다.
*   **⚡ 잭팟 (1%):** 황금 사과 (소설 3장 + **올스탯 +1**)
*   **✨ 영웅 (9%):** `moon moon` 획득
*   **💎 희귀 (40%):** 웹소설 이용권 1장
*   **🪙 일반 (35%):** 공격권 3장 페이백
*   **💨 꽝 (15%):** 녹슨 톱니바퀴 (MP 5 회복)
